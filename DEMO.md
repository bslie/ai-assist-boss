# Демо: сценарий на 3 минуты и чек-лист перед записью

Видео до 3 минут, один дубль. Порядок повторяет сквозной сценарий из SPEC (раздел 9). Что и как показывать — ниже; в скобках, что должно произойти.

## Перед записью (5 минут)

1. `docker compose up -d`, затем `npm run dev` и `npm run worker` (воркер нужен для Telegram и рутин). Для стенда: деплой по пушу в `master`, проверить `/login` в окне инкогнито.
2. Админ → «Демо-стенд» → **Сбросить** демо-часы (07.12.2026 08:30). Если состояние «грязное» (старые карточки, просроченные задачи после перемотки), пересоздать данные: `npm run db:seed`.
3. Привязать Telegram руководителя: `npm run tg:link -- ivan-petrov`; в боте нажать ссылку.
4. Проверить, что в `.env` стенда заданы цены, иначе в «Метриках» будет 0 ₽: `LLM_PRICE_INPUT_RUB_PER_M`, `LLM_PRICE_OUTPUT_RUB_PER_M`, `STAFF_HOUR_RATE_RUB`.
5. Модель: на OpenRouter рассуждение выключено по умолчанию (`LLM_REASONING`), ответ чата 3–6 с, протокол ~8 с. Прогрейте один запрос в чате до записи.
6. Окно браузера 1440×900, тёмная тема системы не нужна, закрыть лишние вкладки и уведомления.

## Сценарий

| Время | Что показать | Что говорим |
|---|---|---|
| 0:00 | `/login` → вход. Главная «Разговор»: заголовок, «Учусь. Сама ничего не отправляю», чип с числом решений | Это не мессенджер: помощник работает через почту, календарь и Telegram. Пока он учится, сам ничего не отправляет |
| 0:20 | Админ → «Демо-стенд» → «Утренний план». В Telegram приходит план и карточки. Утвердить одну, во второй нажать «Поправить», изменить текст | Поправка предлагается запомнить как правило: помощник учится на правках |
| 0:50 | «Новые письма (демо-пачка)» (или `npm run mail:send -- --speed 10`). В «Разговоре» появляется карточка на 18 000 ₽ и пометка «Это уже 2-е письмо по этому вопросу» | Повтор письма не создаёт новую карточку. Деньги, кадры, руководство и обязательства клиентам всегда у руководителя |
| 1:15 | Если в черновике есть подсвеченный «[срок]»: «Вписать [срок]» → значение → отправить | Письмо с незаполненным пропуском не уйдёт |
| 1:25 | «Протокол встречи» (демо-стенд) → в «Разговоре» карточка протокола → «Утвердить и разослать всем» | Аватар задаёт вопросы по прошлому протоколу; протокол с «было → станет» и поручения исполнителям уходят после утверждения |
| 2:00 | Чат: «Что на сегодня?», «Поручи Алексею подготовить сводку по возвратам до пятницы». Затем «порог по деньгам 30 тысяч» → кнопка «Применить» | Любые изменения можно просить словами; что ослабляет защиту, подтверждается кнопкой |
| 2:20 | «Метрики»: часы, доля писем без руководителя, окупаемость, проверка разбора почты (80 из 80, 0 нарушений защиты) | Стоимость одного запроса сравнивается с освобождённым временем по ставке часа |
| 2:40 | «Профиль» → вставить `data/profiles/leader2_profile.md` → «Показать изменения» → «Применить» (или переключиться на Татьяну Громову) | Второй руководитель подключается без правки кода |

## Если что-то пошло не так

- Модель не ответила за 90 с: в интерфейсе появится «Модель отвечает слишком долго», повторите; детали в логе сервера (`[llm]`).
- Карточка уже решена в Telegram — в вебе она пропадёт сама (SSE), статус «Это уже решено в другом месте».
- «Метрики» показывают 0 ₽: не заданы цены в `.env` (см. пункт 4).
- Календарь, почта, Zoom с аватаром требуют реальных подключений в «Подключения»; без них показывайте протокол по транскрипту.
